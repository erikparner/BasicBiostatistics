# Basic Biostatistics Course Notes

This repository contains concise notes for a basic biostatistics course.

## Topics

### Descriptive statistics
- Summarize data with counts, proportions, means, medians, standard deviations, and ranges.
- Use tables and plots to understand the distribution of variables before formal analysis.

### Probability and distributions
- Treat probability as a measure of uncertainty for outcomes in a population or sample.
- Common models include the binomial distribution for counts and the normal distribution for continuous measurements.

### Estimation
- A sample statistic is used to estimate an unknown population parameter.
- Confidence intervals combine an estimate with its uncertainty to give a plausible range for the parameter.

### Hypothesis testing
- Start with a null hypothesis and compare the observed data with what would be expected under that hypothesis.
- Report both the estimated effect and the p-value instead of relying on significance alone.

### Comparing groups
- Two-group comparisons often use a two-sample t-test for continuous outcomes or a chi-squared test for categorical outcomes.
- Paired data should be analyzed with methods that account for matching or repeated measurements.

### Regression
- Linear regression relates a continuous outcome to one or more predictors.
- Logistic regression is used when the outcome is binary, such as disease versus no disease.

## Study approach

1. Describe the data.
2. Choose a model or test that matches the study design and outcome type.
3. Check the assumptions behind the method.
4. Interpret the result in the scientific context, not only by statistical significance.
